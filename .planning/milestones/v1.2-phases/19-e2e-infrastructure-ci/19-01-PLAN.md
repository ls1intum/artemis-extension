<task type="auto">
  <name>Task 2: Create GitHub Actions CI workflow</name>
  <files>iris-thaumantias/.github/workflows/ci.yml</files>
  <action>
Create `iris-thaumantias/.github/workflows/ci.yml` with the following structure:

```yaml
name: CI

on:
  push:
    branches: ['**']
  pull_request:
    branches: [main]

permissions:
  contents: read
  checks: write

jobs:
  test:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: iris-thaumantias

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
          cache-dependency-path: iris-thaumantias/package-lock.json

      - name: Install dependencies
        run: npm ci

      - name: Compile tests
        run: npm run compile-tests

      - name: Create reports directory
        run: mkdir -p reports

      - name: Run Vitest (React component tests)
        run: npm run test:react

      - name: Run Mocha extension host tests
        run: xvfb-run -a npm run test:unit

      - name: Publish test results
        uses: dorny/test-reporter@v2
        if: ${{ !cancelled() }}
        with:
          name: Test Results
          path: iris-thaumantias/reports/*.xml
          reporter: jest-junit
          fail-on-error: 'true'

      - name: Upload JUnit reports
        uses: actions/upload-artifact@v4
        if: ${{ !cancelled() }}
        with:
          name: junit-reports
          path: iris-thaumantias/reports/
```

Key decisions per CONTEXT.md and RESEARCH.md:
- `defaults.run.working-directory: iris-thaumantias` avoids repeating it on every step
- `permissions: checks: write` is required for `dorny/test-reporter` to create Check Runs
- `compile-tests` must run before `test:unit` (Mocha runs compiled JS from `out/`)
- `mkdir -p reports` ensures the directory exists before test runs (Pitfall from RESEARCH.md Open Question 3)
- `xvfb-run -a` only on the Mocha step (Vitest uses happy-dom, no display needed)
- Vitest runs first — if it fails, GitHub Actions skips subsequent steps (early exit by default)
- `if: ${{ !cancelled() }}` on reporter/upload steps ensures results are published even on test failure (but not on workflow cancellation)
- `dorny/test-reporter` path is relative to workspace root, not working-directory — so it must be `iris-thaumantias/reports/*.xml`
- E2E tests are NOT in CI per user decision
