    - Listen for `message` events with `{ type: 'START', endTime: number }` and `{ type: 'STOP' }`
    - On START: clear any existing timer, call tick() immediately, then setInterval(tick, 1000)
    - tick(): calculate `remaining = Math.max(0, endTime - Date.now())`, post `{ type: 'TICK', remaining, expired: remaining === 0 }`
    - On expired (remaining === 0): clearInterval, post final TICK, stop
    - On STOP: clearInterval
    - Use `self.addEventListener('message', ...)` and `self.postMessage(...)` (Worker context)

    **4. Create `hooks/useExamTimer.ts`:**
    - Export `useExamTimer(endTime: number | null): { remaining: number; expired: boolean }`
    - Inside useEffect (dependency: [endTime]):
      - If endTime is null, return early (no timer)
      - Create Worker using inline import pattern. Since esbuild-plugin-inline-worker may use different import conventions, construct the Worker inline with a blob URL approach if the plugin doesn't work. Research recommends: the plugin transforms `?worker` suffix imports into functions that create Worker instances. Try the import pattern first:
        ```typescript
        // The plugin inlines the worker code
        import ExamTimerWorker from '../workers/examTimer.worker';
        ```
        If the plugin requires a different pattern, use the constructor directly. The key requirement is that the Worker code is bundled inline (no separate file).
      - Set up `worker.onmessage` to update state with `{ remaining, expired }` from TICK messages
      - Post `{ type: 'START', endTime }` to start the timer
      - Cleanup: post `{ type: 'STOP' }` then `worker.terminate()`
    - Use `useState` for timer state (NOT Zustand — timer is high-frequency local state per research anti-patterns)

    **5. Create `hooks/useRelativeTime.ts`:**
    - Export `useRelativeTime(targetDate: Date | null): string`
    - Returns relative time strings: "in 2 days", "5 hours ago", "in 1 minute", "less than a minute ago"
    - Uses setInterval(60000) to update every minute (regular setInterval OK — accuracy not critical)
    - Logic: calculate diff in ms, convert to days/hours/minutes, format with "in X" or "X ago"
    - Cleanup: clearInterval on unmount

    **6. Create `utils/formatExamTimer.ts`:**
    - Export `formatExamTimer(ms: number): string`
    - Artemis-compatible format:
      - >= 1 hour: `"1h 7min"` (hours + minutes)
      - >= 10 minutes: `"15min"` (minutes only)
      - 1-10 minutes: `"8min 0s"` (minutes + seconds)
      - < 1 minute: `"45s"` (seconds only)
    - Input is milliseconds remaining

    **7. Create `components/ExamTimer/ExamTimer.tsx` and `.module.css`:**
    - Props: `{ endTime: number; startTime: number; totalDuration: number }` (all in ms)
    - Use `useExamTimer(endTime)` hook for remaining/expired state
    - Use `formatExamTimer(remaining)` for display text
    - Calculate progress percentage: `elapsed = Date.now() - startTime`, `percentage = Math.min(100, (elapsed / totalDuration) * 100)`
    - Progress bar recalculated each render (no separate state needed since timer ticks cause re-render)
    - Warning state: `remaining < 5 * 60 * 1000 && !expired` — apply `.warning` class
    - Expired state: apply `.expired` class
    - CSS: timer text with VS Code theme colors, `.warning` uses red color + pulse animation (@keyframes pulse), progress bar with var(--vscode-progressBar-background), progress container with var(--vscode-editorWidget-background)
