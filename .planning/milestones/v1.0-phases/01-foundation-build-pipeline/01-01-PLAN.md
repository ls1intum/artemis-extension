  <action>
    1. Create `src/views/webview/react/ErrorBoundary.tsx`:
       - Class component implementing React.Component<ErrorBoundaryProps, ErrorBoundaryState>
       - Props: `{ children: React.ReactNode }`
       - State: `{ hasError: boolean; error: Error | null }`
       - `getDerivedStateFromError(error)`: returns `{ hasError: true, error }`
       - `componentDidCatch(error, errorInfo)`: sends error to extension host via `acquireVsCodeApi().postMessage({ type: 'error', error: { message, stack, componentStack } })`
         - NOTE: Do NOT call acquireVsCodeApi() inside componentDidCatch — it can only be called once. Accept it as a prop or use a module-level reference.
         - Better approach: Accept `vscodeApi` as a prop from index.tsx where it's already cached.
       - Fallback render uses VS Code CSS variables for theming:
         - `var(--vscode-errorForeground)` for text
         - `var(--vscode-inputValidation-errorBackground)` for background
         - `var(--vscode-inputValidation-errorBorder)` for border
         - `var(--vscode-button-background)` / `var(--vscode-button-foreground)` for retry button
       - Retry button resets state: `this.setState({ hasError: false, error: null })`
       - Export as named export: `export { ErrorBoundary }`

    2. Create `src/views/webview/react/App.tsx`:
       - Functional component accepting `{ vscodeApi: VsCodeApi }` prop
       - VsCodeApi type: `{ postMessage: (msg: unknown) => void; getState: () => unknown; setState: (state: unknown) => void }`
       - Renders a simple placeholder div with text "Artemis React Webview" (will be replaced in Phase 3)
       - Use VS Code CSS variable for text color: `var(--vscode-foreground)`
       - Export as named export: `export { App }`

    3. Create `src/views/webview/react/index.tsx`:
       - Declare global `acquireVsCodeApi` type on Window interface (or use declare function)
       - Call `acquireVsCodeApi()` once at module scope, cache result
       - Get root container: `document.getElementById('root')`
       - Guard: throw Error if container not found
       - Use `createRoot(container).render(...)` from react-dom/client
       - Render: `<ErrorBoundary vscodeApi={vscode}><App vscodeApi={vscode} /></ErrorBoundary>`
       - After render call: `vscode.postMessage({ type: 'ready' })` to signal readiness to extension host

    IMPORTANT: Use `react-jsx` automatic transform — do NOT add `import React from 'react'` at top of .tsx files (only needed for ErrorBoundary class since it extends React.Component — import React there).
