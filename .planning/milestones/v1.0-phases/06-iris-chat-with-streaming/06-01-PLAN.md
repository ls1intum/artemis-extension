
**Store implementation details:**
- `setIrisState`: Updates context, sessions, recent/all exercises/courses from extension snapshot
- `addMessage`: Appends to messages array. For user messages, set `status: 'sending'` initially
- `updateMessageContent`: Find message by `localId`, update content (used during streaming)
- `startStreaming`: Sets `streaming.isStreaming = true`, `streaming.messageLocalId = localId`, `streaming.visibleChunks = []`
- `appendStreamChunk`: Pushes chunk to `streaming.visibleChunks` array
- `finishStreaming`: Sets `streaming.isStreaming = false`, updates the message's content to `finalContent`, clears streaming state
- `setMessageStatus`: Updates optimistic message status (sending -> sent or error)

Do NOT persist any chat state via `vscodeApi.setState()` — the extension maintains all durable state. Only persist `searchQuery` and `forceContextPicker` in the component (matches legacy behavior from irisChatView.ts line 326-337).

**2. Create `useStreamingMessage.ts` — Token buffering + sentence boundary flushing:**

Per RESEARCH.md Pattern 1 and user decisions:
- Buffer incoming tokens in a mutable ref (no re-render per token)
- Flush buffer on requestAnimationFrame cadence (60Hz, matches display)
- Apply sentence boundary detection before flushing: flush if buffer > 200 chars (~50 tokens) OR ends with `.!?\n`
- When flushing, call `useChatStore.getState().appendStreamChunk(chunk)` to add visible chunk

```typescript
import { useRef, useEffect, useCallback } from 'react';
import { useChatStore } from '../stores/useChatStore';

export function useStreamingMessage() {
    const bufferRef = useRef<string[]>([]);
    const rafIdRef = useRef<number | null>(null);
    const appendStreamChunk = useChatStore(state => state.appendStreamChunk);

    const appendToken = useCallback((token: string) => {
        bufferRef.current.push(token);
    }, []);

    // Sentence boundary detection
    const shouldFlush = useCallback((buffer: string): boolean => {
        if (buffer.length > 200) return true;  // ~50 tokens
        if (/[.!?\n]$/.test(buffer)) return true;
        return false;
    }, []);

    // RAF flush loop
    useEffect(() => {
        const flush = () => {
            if (bufferRef.current.length > 0) {
                const accumulated = bufferRef.current.join('');
                if (shouldFlush(accumulated)) {
                    bufferRef.current = [];
                    appendStreamChunk(accumulated);
                }
            }
            rafIdRef.current = requestAnimationFrame(flush);
        };
        rafIdRef.current = requestAnimationFrame(flush);

        return () => {
            if (rafIdRef.current !== null) {
                cancelAnimationFrame(rafIdRef.current);
            }
            // Flush remaining buffer on cleanup
            if (bufferRef.current.length > 0) {
                const remaining = bufferRef.current.join('');
                bufferRef.current = [];
                appendStreamChunk(remaining);
            }
        };
    }, [shouldFlush, appendStreamChunk]);

    // Force flush (used when streaming ends)
    const forceFlush = useCallback(() => {
        if (bufferRef.current.length > 0) {
            const remaining = bufferRef.current.join('');
            bufferRef.current = [];
            appendStreamChunk(remaining);
        }
    }, [appendStreamChunk]);

    return { appendToken, forceFlush };
}
```

**3. Create `useAutoScroll.ts` — Smart scroll with user intent:**

Wrap `use-stick-to-bottom` library per RESEARCH.md Pattern 4:
- Auto-scroll if user is near bottom
- Stop if user scrolls up to read history
- Resume on new user message send

```typescript
import { useRef, useCallback } from 'react';
import { useStickToBottom } from 'use-stick-to-bottom';

export function useAutoScroll() {
    const { scrollRef, contentRef, isAtBottom, scrollToBottom } = useStickToBottom();

    // Scroll to bottom when user sends a message (explicit intent to follow conversation)
    const scrollOnSend = useCallback(() => {
        scrollToBottom();
    }, [scrollToBottom]);

    return {
        scrollRef,       // Attach to scroll container div
        contentRef,      // Attach to content wrapper div inside scroll container
        isAtBottom,      // Whether user is near bottom (for UI indicators)
        scrollOnSend,    // Call after sending a message
        scrollToBottom,  // Manual scroll to bottom
    };
}
```

Check the `use-stick-to-bottom` API carefully — it may use `StickToBottomProvider` + `useStickToBottomContext` instead of a single hook.
