    **5. Modify ViewRouter.ts** for coexistence:

    - Import `getReactWebviewHtml` from `../../utils/webviewHelpers`
    - Add a private readonly Map `_reactViews` mapping view state names to booleans: `new Map([['git-credentials', true]])`
    - In `getHtml()`, BEFORE the existing switch statement, check: if `this._reactViews.get(state)` is true AND `this._webview` exists, return `getReactWebviewHtml(this._webview, this._extensionContext.extensionUri, this._stateToViewName(state))`
    - Add a private `_stateToViewName(state: AppState): string` method that maps AppState values to React view names (e.g., `'git-credentials'` -> `'gitCredentials'`, `'service-status'` -> `'serviceStatus'`, etc.)
    - Legacy HTML generation stays completely untouched for non-React views

    **6. Modify ArtemisWebviewProvider.ts** for ready-signal handshake:

    - Add private fields: `private _webviewReady = false;` and `private _pendingMessages: any[] = [];`
    - In `resolveWebviewView()`, set `this._webviewReady = false;` at the start
    - In the `onDidReceiveMessage` handler, check if `message.type === 'ready'`: if so, set `_webviewReady = true`, flush `_pendingMessages` via `this._view?.webview.postMessage()`, clear `_pendingMessages`, then send initial state for the current view
    - For non-'ready' messages with `message.type === 'command'`, extract `message.command` and delegate to `this._messageHandler.handleMessage({ command: message.command, ...message.payload })` to bridge the new typed message format to the existing command handler system
    - For messages with `message.command` (legacy format), continue delegating to `this._messageHandler.handleMessage(message)` as before
    - Add a private `_postMessageSafe(message: any)` method that checks `_webviewReady`: if true, post directly; if false, push to `_pendingMessages`
    - Update `setMessageSender()` to use `_postMessageSafe` when the current state maps to a React view
    - Reset `_webviewReady = false` whenever the view re-renders (in `render()` method) since re-render reloads the webview HTML

    **7. Create views barrel** at `src/views/webview/react/views/index.ts`:
