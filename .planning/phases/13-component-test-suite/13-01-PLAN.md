**Container:** Test children rendering, optional title display, semantic section/div element
**EmptyState:** Test message text display, optional icon rendering, optional action button
**List:** Test rendering with items, empty state, list semantics (ul/ol)
**ListItem:** Test content rendering, click handler, active/selected state, semantic li element
