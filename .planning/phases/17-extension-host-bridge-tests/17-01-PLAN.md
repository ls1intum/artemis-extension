<objective>
Refactor WebSocketStatusBarService from a developer-only debug panel into a user-facing WebSocket connection indicator with an override rule that always shows the status bar when disconnected. Add a public `reconnectAttempts` getter to `ArtemisWebsocketService`. Write Mocha tests verifying all visibility transitions.

Purpose: Users currently see infinite loading when WebSocket drops — they have no way to know the connection is broken or to manually retry. The status bar item makes connection state visible and actionable.
Output: Refactored `WebSocketStatusBarService`, new VS Code setting `artemis.showWebSocketStatusBar`, reconnect attempt getter, and passing Mocha tests.
</objective>
