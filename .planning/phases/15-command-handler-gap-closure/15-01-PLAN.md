    Add `openExternalLink` and `openImagePreview` handlers to `UtilityCommandModule.getHandlers()` and implement the handler methods. Add `import * as crypto from 'crypto'` at the top for temp file naming.

    **Handler 1: `handleOpenExternalLink`**

    Per user decisions (all locked, non-negotiable):

    1. **Input validation:** Extract `url` from `message.payload.url` (note: message contracts use `payload` wrapper). If missing or not a string, show error via `vscode.window.showErrorMessage` and return.

    2. **Protocol validation (defense-in-depth):** Parse the URL with `new URL(url)`. Only allow `http:` and `https:` protocols. If invalid protocol or unparsable URL, show error message `'Invalid URL protocol. Only http:// and https:// links are allowed.'` with a 'Copy URL' action button. If user clicks 'Copy URL', copy the raw URL to clipboard via `vscode.env.clipboard.writeText(url)`. Log the error via `logger.error()` with `LogCategory.VIEW`.

    3. **Domain extraction:** Extract hostname from parsed URL for trusted domain checking.

    4. **Trusted domain check:** Read trusted domains from `this.context.extensionContext.globalState.get<string[]>('artemis.trustedDomains', [])`. Validate it's an array (corruption recovery -- if not array, treat as empty). If domain is trusted, open directly via `vscode.env.openExternal(vscode.Uri.parse(url))` and return.

    5. **Confirmation dialog (untrusted domain):** Show a modal information message:
       - Message: `'Open external link?\n\n{truncatedUrl}'` where truncatedUrl is `url.slice(0, 77) + '...'` if url.length > 80, else url as-is
       - Options: `{ modal: true }` with buttons `'Open'` and `'Trust this domain'`
       - Do NOT add a Cancel button (modal provides implicit dismiss)
       - If result is `'Open'`: open via `vscode.env.openExternal(vscode.Uri.parse(url))`
       - If result is `'Trust this domain'`: push domain to trusted domains array, save via `globalState.update('artemis.trustedDomains', updatedArray)`, then open the URL
       - If result is undefined (dismissed): do nothing

    6. **Error handling:** Wrap the entire handler in try/catch. On error, log via `logger.error('Open external link error:', LogCategory.VIEW, error)` and show error message with 'Copy URL' fallback button.

    **Handler 2: `handleOpenImagePreview`**

    Per user decisions (all locked):

    1. **Input validation:** Extract `uri` from `message.payload.uri`. If missing or not a string, show error and return.

    2. **Data URI handling (uri.startsWith('data:')):**
       - Parse the data URI: split on first comma, check for `;base64` in metadata portion
       - Extract mime type from metadata (default to `'image/png'` if empty)
       - Decode: if base64, use `Buffer.from(data, 'base64')`; if URL-encoded, use `Buffer.from(decodeURIComponent(data))`
       - If parsing fails, show error `'Failed to decode image data'` and return
       - Infer file extension from mime type using a map: `image/png` -> `.png`, `image/jpeg` -> `.jpg`, `image/jpg` -> `.jpg`, `image/gif` -> `.gif`, `image/svg+xml` -> `.svg`, `image/webp` -> `.webp`, default `.png`
       - Generate temp file name: `image-${crypto.randomBytes(8).toString('hex')}${extension}`
       - Create temp file URI: `vscode.Uri.joinPath(this.context.extensionContext.globalStorageUri, tempFileName)`
       - Ensure directory exists: `await vscode.workspace.fs.createDirectory(this.context.extensionContext.globalStorageUri)`
       - Write file: `await vscode.workspace.fs.writeFile(tempFileUri, buffer)` (where buffer is a `Uint8Array` -- Buffer extends Uint8Array so this works)
       - Open in VS Code viewer: `await vscode.commands.executeCommand('vscode.open', tempFileUri)`
       - No cleanup needed (see research: skip cleanup for v1.1, VS Code cleans on uninstall)

    3. **Remote URL handling (not a data URI):**
       - Validate protocol (http/https only), same as openExternalLink
       - If invalid protocol, show error and return
       - Open in default browser via `vscode.env.openExternal(vscode.Uri.parse(uri))`
       - No confirmation dialog for images (per user decision: images are content, not navigation)

    4. **Error handling:** Wrap in try/catch. Log via `logger.error('Open image preview error:', LogCategory.VIEW, error)`. Show error message with 'Copy URL' action button as fallback.

    **Private helper methods to add to the class:**

    - `isAllowedProtocol(url: string): boolean` -- Parse with `new URL(url)`, return `parsed.protocol === 'http:' || parsed.protocol === 'https:'`. Return `false` on parse failure.
    - `extractDomain(url: string): string | null` -- Parse with `new URL(url)`, return `parsed.hostname`. Return `null` on parse failure.
    - `truncateUrl(url: string, maxLength: number = 80): string` -- If `url.length <= maxLength` return url, else `url.slice(0, maxLength - 3) + '...'`.
    - `parseDataUri(dataUri: string): { mimeType: string; data: Buffer } | null` -- Implementation from research code examples (handle both base64 and URL-encoded, handle missing mime type, handle commas in data).
    - `getExtensionFromMime(mimeType: string): string` -- Map lookup with `.png` default.

    **Register handlers in `getHandlers()`:** Add to the returned object:
    ```
    openExternalLink: this.handleOpenExternalLink,
    openImagePreview: this.handleOpenImagePreview,
    ```
