```typescript

    message: WebviewToExtensionMessage
): T['payload']

// Problem: Inline types like { type: 'command'; command: 'alert'; payload: AlertPayload }
// are NOT members of the union, so TS2344 fires.
// Fix: Either add these command types to the union, or relax the constraint.
```
