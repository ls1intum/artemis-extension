1. Create `iris-thaumantias/knip.json` with the following configuration:
```json
{
  "$schema": "https://unpkg.com/knip@5/schema.json",
  "entry": [
    "src/extension.ts",
    "src/views/webview/react/index.tsx"
  ],
  "project": [
    "src/**/*.{ts,tsx}"
  ],
  "ignoreDependencies": ["vscode"],
  "ignore": ["test/**", "esbuild.js"]
}
```

2. Run `npx knip@5` from `iris-thaumantias/` directory. Capture the output.

3. For each dependency knip flags as unused, MANUALLY verify by searching imports before removing:
   - Search `grep -r "from ['\"]<dep-name>" src/` and `grep -r "require(['\"]<dep-name>" src/ esbuild.js`
   - If the dep has confirmed imports in production source: keep it, do NOT remove
   - If the dep has NO imports anywhere in src/ or build scripts: remove it with `npm uninstall <dep>`
   - Known false-positive risk: `ws` and `@stomp/stompjs` are used in `src/services/artemisWebsocketService.ts` — do NOT remove even if knip flags them

4. Fix misplaced dependencies:
   - Move `clsx` from devDependencies to dependencies: `npm uninstall clsx && npm install clsx@^2.1.1`
   - Move `@types/katex` from dependencies to devDependencies: `npm uninstall @types/katex && npm install -D @types/katex@^0.16.8`

5. Run `npm audit` and capture output. Assess findings:
   - Production dependency vulnerabilities (HIGH/CRITICAL): fix immediately
   - DevDependency-only vulnerabilities: document as accepted risk (all current findings are devDep transitive chains — minimatch ReDoS in @vscode/test-cli, etc.)
   - Do NOT add npm overrides or downgrade direct deps to fix transitive devDep issues

6. After all changes, delete `node_modules/` and `package-lock.json`, then run `npm install` to regenerate a clean lock file.

7. Verify the build still works: run `npm run check-types` and `npm run compile`.
