  <action>
    Install CSS Modules dependencies:
    ```bash
    cd iris-thaumantias && npm install --save-dev esbuild-css-modules-plugin typescript-plugin-css-modules clsx
    ```

    Create TypeScript CSS Modules declaration at `src/views/webview/react/types/css-modules.d.ts`:
    ```typescript
    declare module '*.module.css' {
      const classes: { readonly [key: string]: string };
      export default classes;
    }
    ```

    Update `tsconfig.json` — add `typescript-plugin-css-modules` plugin to compilerOptions:
    ```json
    "plugins": [
      { "name": "typescript-plugin-css-modules" }
    ]
    ```

    Update `esbuild.js` — add `esbuild-css-modules-plugin` to the React webview build context (`webviewReactCtx`):
    - Import at top: `const cssModulesPlugin = require('esbuild-css-modules-plugin');`
    - Add `cssModulesPlugin()` to the `plugins` array BEFORE `esbuildProblemMatcherPlugin`
    - Keep the `.css` loader default (the plugin handles .module.css files)

    Copy `media/styles/base.css` to `src/views/webview/react/styles/base.css`. This is the global theme variable file. The React entry point (index.tsx) should import it so all components get --theme-* variables. Add `import './styles/base.css';` to `src/views/webview/react/index.tsx` at the top (before App import).

    Verify the build still works after all changes with `npm run compile` and `npm run check-types`.
  </action>

    Port the following HTML-string components to React. Reference the existing source files for exact styling and behavior. Use CSS Modules with `clsx` for conditional classes. All components use `--theme-*` CSS variables (keep the abstraction layer per user decision).

    **Button.tsx** — Port from `buttonComponent.ts` + `button.css`:
    - Props interface: `children: ReactNode`, `onClick?: () => void`, `variant?: 'primary' | 'secondary' | 'icon' | 'link' | 'ghost'`, `disabled?: boolean`, `className?: string`, `fullWidth?: boolean`, `icon?: ReactNode`, `width?: string`, `height?: string`, `alignText?: 'left' | 'center' | 'right'`, `type?: 'button' | 'submit' | 'reset'`
    - Use `clsx()` for conditional class composition
    - Handle icon-only (icon + no children), icon+label, and label-only rendering
    - `Button.module.css` — Port all styles from `button.css` to CSS Modules. Keep all --theme-* variable references. Use `.btn`, `.btnPrimary`, `.btnSecondary`, `.btnIcon`, `.btnLink`, `.btnGhost`, `.btnFullWidth`, `.btnDisabled`, `.btnWithIcon`, `.btnFixedSize`, `.btnLabel`, `.btnIconSlot` as camelCase class names for clean TypeScript access (avoid kebab-case to skip bracket notation)

    **IconButton.tsx** — Consolidated from 7 icon button files + `iconButtons.css`:
    - Props interface: `icon: ReactNode`, `onClick?: () => void`, `ariaLabel: string`, `disabled?: boolean`, `className?: string`
    - Named preset exports as static properties:
      - `IconButton.Close` — SVG from closeButton.ts
      - `IconButton.Checkmark` — SVG from checkmarkButton.ts
      - `IconButton.BurgerMenu` — SVG from burgerMenuButton.ts
      - `IconButton.Collapse` — SVG from collapseButton.ts (accepts `collapsed: boolean` prop to rotate icon)
      - `IconButton.Fullscreen` — SVG from fullscreenButton.ts
      - `IconButton.Reload` — SVG from reloadButton.ts
      - `IconButton.Settings` — SVG from settingsButton.ts
    - Each preset renders an inline `<svg>` element (not dangerouslySetInnerHTML). Extract SVG paths from the existing icon button files. Use `currentColor` for fill/stroke so icons inherit text color.
    - `IconButton.module.css` — Port from `iconButtons.css`

    **Badge.tsx** — Port from `badgeComponent.ts` + `badge.css`:
    - Props interface: `children: ReactNode`, `variant?: 'default' | 'success' | 'warning' | 'error' | 'info' | 'muted'`, `className?: string`
    - Each variant maps to status CSS variables (--theme-success-background, --theme-error-foreground, etc.)
    - `Badge.module.css` — Port from `badge.css`

    **BackLink.tsx** — Port from `backLinkComponent.ts` + `back-link.css`:
    - Props interface: `children: ReactNode`, `onClick?: () => void`, `className?: string`
    - Renders a back-arrow icon followed by label text. Use inline SVG for the arrow.
    - `BackLink.module.css` — Port from `back-link.css`

    **index.ts files** — Each component folder gets an index.ts re-exporting the component:
    - `Button/index.ts`: `export { Button } from './Button'; export { IconButton } from './IconButton';`
    - `Badge/index.ts`: `export { Badge } from './Badge';`
    - `BackLink/index.ts`: `export { BackLink } from './BackLink';`

    All components must:
    - Use functional component syntax (no classes except ErrorBoundary)
    - Accept an optional `className` prop for external styling
    - Use `type="button"` on all `<button>` elements to prevent accidental form submission
    - Include appropriate ARIA attributes where the originals lacked them
