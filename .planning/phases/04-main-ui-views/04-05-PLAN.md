## Root Cause Analysis

Two diagnosed blocker issues affect ALL Phase 4 React views:

**Root Cause 1: Missing CSS stylesheet**
`getReactWebviewHtml()` in `webviewHelpers.ts` only loads `base.css`. The esbuild output also produces `dist/webview-react.css` (74KB, all CSS module styles), but no `<link>` tag references it. Result: all CSS module classes resolve to the correct class names but have no style definitions.

**Root Cause 2: Infinite render loop**
The mount lifecycle for views triggers a reload command (e.g., DashboardView calls `loadDashboard()` which sends `reloadDashboard` command). The reload command handler in `navigationCommands.ts` calls `showDashboard()` on the provider, which calls `render()`, which replaces `webview.html`, destroying the React app. React remounts, the useEffect fires again, and the cycle repeats infinitely causing flickering.

The ready-signal handshake in `artemisWebviewProvider.ts` already sends init data for each view on the `ready` message. CourseList, CourseDetail, and ExerciseDetail already send `{ type: 'ready' }` on mount and handle the init response. Dashboard does NOT send ready -- it calls `loadDashboard()` instead.

## Key Insight

The fix has two parts:
1. Add the missing CSS link tag
2. Break the render loop by ensuring views get data via postMessage (not via render()):
   - Dashboard: Remove `loadDashboard()` from initial useEffect, add `vscodeApi.postMessage({ type: 'ready' })` instead (matching the pattern CourseList/CourseDetail/ExerciseDetail already use)
   - All reload command handlers: Re-fetch data and send via `this.context.sendMessage()` instead of calling `showXxx()` -> `render()`
   - The `loadArchivedCourses` handler also calls `render()` after sending the typed message -- remove the `render()` call since the React app handles `archivedCoursesLoaded` messages already
</context>

    if (currentState === 'dashboard') {

                    return bDate.localeCompare(aDate);
                });
            return {

            };
        });
        this._postMessageSafe({
            type: 'dashboardInit',

        const courses = coursesData?.courses || [];

        const { detectWorkspaceExercise } = require('../services');
